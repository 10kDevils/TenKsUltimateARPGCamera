# 10k's Ultimate ARPG Camera

An action-RPG style camera for World of Warcraft (built for WoW Forever, interface 16001).

- **Situations**: Exploration, Combat, Indoors, Swimming, City, Talk and Dungeon / Raid each get their own field of view, shoulder offset, zoom, tilt, vignette and letterbox bars, and the camera eases between them.
- **Presets**: Default, Cinematic, Tactical, Comfort and Controller, plus shareable settings codes.
- **Targeting frame**: the Halo ring drains with your target's health, pulses while it casts, marks elites and shows the distance. Four other styles are included.
- **Controller friendly**: a Controller preset for the couch or a Steam Deck, and a settings window you can drive with a gamepad.

## Install

1. Open the [latest release](../../releases/latest) and download `TenKsUltimateARPGCamera-<version>.zip`.
2. Extract it into `World of Warcraft/_retail_/Interface/AddOns/` (or the AddOns folder of your WoW Forever install) so you end up with `AddOns/TenKsUltimateARPGCamera/TenKsUltimateARPGCamera.toc`.
3. Type `/acam` in game to open the settings.

**WowUp**: *Get Addons → Install from URL* and paste this repository's address. WowUp then updates it whenever a new release is published.

## Commands

`/acam` opens the settings window. `/acam help` lists everything else.
